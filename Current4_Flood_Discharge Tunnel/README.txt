CURRENT 4 FLOOD SAFETY WEBSITE

Files:
- index.html       Home page
- about.html       About Current 4 and the Taungoo project
- safety-tips.html Flood safety advice
- before-after.html Before and during a flood checklist
- solution.html    Underground discharge tunnel concept
- style.css        Shared soft-blue styling
- current4-logo.png Your Current 4 logo

How to open:
1. Download and extract the ZIP.
2. Keep all files in the same folder.
3. Open index.html in a web browser.
4. Click the navigation links to move between pages.

Notes:
- The site uses beginner-friendly HTML and CSS, with no JavaScript.
- The home-page hero uses an online photo, so internet access is needed for that background image.
- The social icons link to general social websites. Replace them with your group's real social page links if you make them.
- This is a school project concept, not a construction-ready engineering design.
